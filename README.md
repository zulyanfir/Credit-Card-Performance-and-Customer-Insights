# Credit-Card-Performance-and-Customer-Insights 

This is a dummy project from the results of my learning in the online course, MySkill. This project is a dashboard to find out insights from credit card users to make the right decisions in business made using Looker Studio tools. 
This project was created to answer several business questions:
1. What is the distribution of the number of customers by domicile and in terms of their background?
2. Which customers with which backgrounds are the most profitable?
3. What is the number and percentage distribution of accounts with a high risk of loss?
